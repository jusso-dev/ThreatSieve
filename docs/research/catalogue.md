# Threat-intelligence reference coverage

Catalogue: [awesome-threat-intelligence at the reviewed commit](https://github.com/hslatman/awesome-threat-intelligence/blob/e506c8415406d6d6ad16040c19c23ddb9ed654ac/README.md). Reviewed 6 October 2026.

All **244 named entries** were inventoried and assessed for product relevance. Primary text was retrieved for **184**, **57** primary requests were unavailable, and **3** were metadata-only resources. HTTP success does not establish project maintenance, safety, availability of a paid feature, or licence compatibility. Some returned pages were login shells, moved product pages or unrelated sites. The decisions below distinguish deeper workflow review from catalogue-level triage.

This is a product/workflow review, not an exhaustive security or source-code audit of 244 external systems. Links inside those projects were not recursively crawled. No external project was installed or executed. No feed was enabled from this inventory. See [design decisions](../tip-ux-review.md) for the primary references used to implement changes.
