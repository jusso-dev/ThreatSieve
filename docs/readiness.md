## Measured robustness and load checks

The live challenge dataset contains six binary maliciousness cases, three bounded actor cases and one deliberately unlabelled insufficient-evidence case. Clef-flash missed two stipulated malicious cases at the raw 0.5 cutoff; full Clef classified all six binary cases correctly. Replaying both measured responses through the production decision engine escalated all ten cases, retained review requirements and left insufficient evidence unknown. No unsupported ATT&CK mapping or invented actor was emitted. This tiny synthetic suite does not justify threshold changes or a calibrated accuracy claim.

Generate the challenge dataset with `pnpm exec tsx scripts/evaluation-challenges.ts`; run `pnpm exec tsx scripts/evaluate-live.ts <private-dataset> --live` with scoped Cloudflare credentials. At most 200 paid model calls are permitted per run. Inputs, raw probabilities and reports stay in ignored private artifacts. Analyst-labelled datasets must include reviewer, rationale, label timestamp and evidence links.

`pnpm exec tsx scripts/benchmark.ts 10000` measured local Miniflare normalization/provenance/D1 persistence at 30.49 input records/second with concurrency eight (p50 235.45 ms, p95 409.95 ms, p99 535.11 ms). It excludes network, Cloudflare Queues, remote AI and analyst traffic and is not a production capacity/SLA claim.

No production data deletion, retention shortening, billing charge, public OpenCTI exposure or customer data sharing is implied by implementation of these controls. Destination credentials must be configured through encrypted secrets, not committed or pasted into reports.
