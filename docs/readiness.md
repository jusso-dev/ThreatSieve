## Measured robustness and load checks

The live challenge dataset contains six binary maliciousness cases, three bounded actor cases and one deliberately unlabelled insufficient-evidence case (10 cases total; 9 labelled). Clef-flash missed two stipulated malicious cases at the raw 0.5 cutoff; full Clef classified all six binary cases correctly. Replaying both measured responses through the production decision engine escalated all ten cases, retained review requirements and left insufficient evidence unknown. No unsupported ATT&CK mapping or invented actor was emitted. This tiny synthetic suite does not justify threshold changes or a calibrated accuracy claim.

Generate the challenge dataset with `pnpm exec tsx scripts/evaluation-challenges.ts`; run `pnpm exec tsx scripts/evaluate-live.ts <private-dataset> --live` with scoped Cloudflare credentials. At most 200 paid model calls are permitted per run. Inputs, raw probabilities and reports stay in ignored private artifacts. Analyst-labelled datasets must include reviewer, rationale, label timestamp and evidence links.

`pnpm exec tsx scripts/benchmark.ts 10000` measured local Miniflare normalization/provenance/D1 persistence at 30.49 input records/second with concurrency eight (p50 235.45 ms, p95 409.95 ms, p99 535.11 ms). It excludes network, Cloudflare Queues, remote AI and analyst traffic and is not a production capacity/SLA claim.

No production data deletion, retention shortening, billing charge, public OpenCTI exposure or customer data sharing is implied by implementation of these controls. Destination credentials must be configured through encrypted secrets, not committed or pasted into reports.

## Deployed acceptance — 7 October 2026

Application commit [`ba049e4`](https://github.com/jusso-dev/ThreatSieve/commit/ba049e43d6ef9202be92f8773ecdbb45ebf55d0e) passed [CI](https://github.com/jusso-dev/ThreatSieve/actions/runs/37605041612): 100 unit/integration tests, 87 full-stack end-to-end tests, eight browser regressions and 13 Python connector/operations tests (208 distinct tests). Migration validation repeats the 21 integration cases. Strict TypeScript, lint, build, security checks and offline evaluation also passed. JavaScript production dependency audit was clear; the Python audit has one narrowly documented upstream advisory exception with two advisory identifiers. See [dependency security](dependency-security.md).

Production API version `96c10b39-dbb4-49be-81ac-47e77574c747` includes MFA, queued collection packages, batched public embeddings and bounded curated-collection matching. The production web version is `7c6853dd-9b44-4813-8880-77e00eabc6ce`. Migrations through 0018 are applied in both environments.

Live acceptance verified a production collection package containing five STIX objects across three nonempty parts, each with a matching checksum and independent STIX parser validation. A synthetic staging observation exercised semantic candidate retrieval followed by Clef-flash/full escalation; the result retained human review and emitted no unsupported ATT&CK or actor assertion. The production `example.com` assessment remained unknown with no ATT&CK mapping or actor attribution.

The public knowledge index contains 5,243 vectors, verified against Vectorize itself after asynchronous indexing completed. Retrieval is enabled in both environments and persisted in GitHub environment configuration. The production pipeline transport backlog was replayed through generation-fenced jobs and cleared; the only remaining operational warnings at acceptance were the missing ThreatFox and URLhaus credentials.

A separate staging API read smoke completed 40 requests at concurrency four, all HTTP 200, in 1.904 seconds (p50 162 ms; p95 469 ms). This small dataset/read-only test does not establish sustained capacity or model cost. All 26 repository screenshots are linked in the README. Private payloads, credentials, raw model responses and backup artifacts remain excluded from Git.
